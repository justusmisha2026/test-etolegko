## Требования и приёмка

- VERIFY-01: симулятор должен выбрать Google для AU, оффер для другой/неизвестной страны и корректно обработать повтор. Фиксировать фактический результат, не заменять его проверкой JSON. Использовать только кампанию 216565; после проверки выключить. Повторное включение отклонено auto-review даже после текущего запроса; до отдельного явного подтверждения не выполнять. Проверка остаётся заблокированной.
- VERIFY-02: браузерные E2E проходят через настоящий UI и HTTP локального приложения: создание и журнал; добавление/удаление и запрет последнего оффера; конфликт двух форм; возврат выключенной привязки; отмена состава с восстановлением неравных долей. Хранилище должно быть новым для каждого теста.
- VERIFY-03: GitHub Actions запускает Ruff, Python-тесты, Node-тесты и Chromium E2E на push/pull_request и вручную. При сбое сохраняет диагностические артефакты. Успех CI подтверждается завершённым запуском GitHub Actions, а не наличием YAML.
- VERIFY-04: README содержит воспроизводимые команды; отчёт различает выполненные проверки и ограничения видео/стенда.

## Решения и риски

Предлагаемая реализация: pytest-playwright, локальный Uvicorn на свободном loopback-порту и внедрённый DemoKeitaro. Подготовка фикстур допускается напрямую в тестовом хранилище до запуска сервера; действия пользователя выполняются через браузер. В production-код тестовые endpoints не добавляются. Миграции продукта не меняются.

Настройки тестового приложения передаются явно с `_env_file=None`, demo=True и пустым ключом; CI не получает секреты Keitaro. Это исключает запись на стенд из E2E. Проверки браузера не подтверждают внешнюю геобазу Keitaro.

Документация: [pytest-playwright](https://playwright.dev/python/docs/test-runners), [GitHub Python CI](https://docs.github.com/en/actions/tutorials/build-and-test-code/python), [симуляция Keitaro](https://docs.keitaro.io/en/campaigns-and-streams/simulation.html).

Полное соответствие недоступной части видеореференса остаётся неподтверждённым; действуют уточнённые пользователем правила. Откат CI/E2E — удаление добавленных тестовых файлов и workflow; данные Keitaro не затрагиваются.
